# הספרייה השקטה - חדר בריחה (דמו)

פרויקט React עצמאי שמריץ את המשחק בלי תלות בסביבת קלוד. מפתח ה-API
נשמר בצד שרת בלבד (בתיקיית `api/`), כך שאפשר להעלות אתר ציבורי
שכל אחד יכול לפתוח בטלפון בלי חשבון קלוד.

## מבנה הפרויקט

```
├── src/
│   ├── App.jsx        # כל לוגיקת המשחק (חידות, צ'אט, סצנת החדר)
│   └── main.jsx        # נקודת הכניסה של React
├── api/
│   └── chat.js         # פונקציית שרת שמחזיקה את מפתח ה-API בסודיות
├── index.html
├── package.json
└── .env.example         # תבנית למשתנה הסביבה הנדרש
```

## שלב 1: קבלת מפתח API (חינמי)

1. היכנסו ל-https://console.groq.com והתחברו עם Google או אימייל (לוקח כ-30 שניות, בלי כרטיס אשראי).
2. לכו ל-https://console.groq.com/keys ולחצו "Create API Key".
3. שכבת ה-free tier נדיבה יחסית: 30 בקשות בדקה, אלפי בקשות ביום - סביר שלא תרגישו את המגבלה בכלל בשימוש אישי/דמו. פרטים מלאים: https://console.groq.com/docs/rate-limits

## שלב 2: הרצה מקומית (רשות, לבדיקה לפני העלאה)

```bash
npm install
cp .env.example .env.local
# ערכו את .env.local והכניסו את המפתח האמיתי שלכם (GROQ_API_KEY)

npm install -g vercel   # אם עדיין אין לכם
vercel dev              # מריץ גם את ה-frontend וגם את פונקציית ה-api יחד מקומית
```

(הרצת `npm run dev` הרגילה תריץ רק את ה-frontend, בלי פונקציית ה-api - לכן לבדיקה מקומית מלאה צריך `vercel dev`.)

## שלב 3: העלאה לאוויר עם Vercel (חינמי)

**אופציה א' - דרך האתר (הכי פשוט):**

1. העלו את התיקייה הזו לריפוזיטורי חדש ב-GitHub.
2. היכנסו ל-https://vercel.com, התחברו עם GitHub, ולחצו "Add New Project".
3. בחרו את הריפוזיטורי - Vercel יזהה אוטומטית שזה פרויקט Vite.
4. לפני שלוחצים Deploy: תחת "Environment Variables" הוסיפו
   `GROQ_API_KEY` עם הערך של המפתח שלכם.
5. לחצו Deploy. תוך דקה תקבלו קישור ציבורי (למשל `escape-room-xyz.vercel.app`).

**אופציה ב' - דרך שורת הפקודה, בלי GitHub:**

```bash
npm install -g vercel
vercel login
vercel --prod
# כשתתבקשו, הוסיפו את משתנה הסביבה:
vercel env add GROQ_API_KEY production
```

## שלב 4: שליחה לחברות

הקישור הציבורי שקיבלתם (`https://your-project.vercel.app`) עובד בכל
דפדפן, כולל בטלפון - בלי צורך בהתקנה או בחשבון קלוד. אפשר לשלוח אותו
ישירות בוואטסאפ.

## עלויות

Vercel: חינמי לפרויקטים אישיים בסדר גודל כזה.
Groq: השכבה החינמית (30 בקשות בדקה, בלי כרטיס אשראי) אמורה להספיק בנוחות
לשימוש אישי ולכמות שיחות של כמה חברות שמנסות דמו. אם בכל זאת תיתקלו
במגבלה, אפשר להוסיף כרטיס אשראי ולקבל פי 10 מהמכסה בלי עלות מינימלית -
פרטים: https://console.groq.com/docs/rate-limits

## הרחבה לחדרים נוספים

כל מה שצריך זה להוסיף עוד אובייקטים בסגנון `ROOM` בקובץ `src/App.jsx`
(או לפצל לקובץ `data/rooms.js` נפרד כשהפרויקט יגדל) - שאר הקוד
(הצ'אט, בדיקת התשובות, מנגנון הרמז) כבר גנרי ויעבוד על כל חדר חדש.
